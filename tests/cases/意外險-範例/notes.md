# 意外險 測試案例說明

## 這個資料夾放什麼
- `input.pdf` ── 真實條款 PDF（建議：常見的個人傷害保險附約）
- `expected.json` ── 手動標記的正確分析輸出

## 填寫 expected.json 時，哪裡最容易出錯

### 1. 骨折附表換算
條款通常有一張「骨折未住院給付表」，列出各部位係數（如：大腿股骨完全骨折 = 35%）。

正確填法：
- 找保額（如 500,000 元）× 最高係數（如 35%）= 175,000
- fracture 填：`"最高175,000｜依部位比例，大腿完全骨折為最高"`

錯誤填法：`"最高175,000（500,000×35%）"` ← 不能有計算式

### 2. 加護病房換算
「另給付住院日額之 N 倍」型：
- 如住院日額 500，另給付住院日額之 1 倍
- 加護病房 = 500 + 500 = 1,000
- icu 填：`"1,000元/日｜最高30日"`

### 3. 意外身故失能保額
通常寫「意外傷害保險金額（即保額）」，直接填用戶輸入的保額。
- 如用戶輸入 200 萬：`deathDisability` 填 `"200萬｜依等級比例（1級=100%）"`
